# OpenBible.info Cross References

Source officielle : https://www.openbible.info/labs/cross-references/

Le jeu de données de références croisées est fourni par OpenBible.info sous
licence Creative Commons Attribution 4.0 International (CC BY 4.0) :
https://creativecommons.org/licenses/by/4.0/

ECHO BIBLE convertit les références et leurs votes en SQLite. Aucun texte de
Bible anglais provenant de la page ou du dataset n’est redistribué ; les
passages affichés sont lus dans la version française installée dans `bible.db`.
