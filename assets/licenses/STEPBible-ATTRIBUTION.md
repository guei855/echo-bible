# STEPBible — attribution

ECHO BIBLE utilise les jeux TBESH et TBESG créés par STEPBible à partir de
travaux de Tyndale House Cambridge.

- Source : <https://github.com/STEPBible/STEPBible-Data>
- Projet : <https://www.stepbible.org/>
- Licence annoncée par la source : Creative Commons Attribution 4.0
  (CC BY 4.0)
- Attribution demandée : « STEP Bible », avec un lien vers
  <https://www.stepbible.org/>.

Les données sont reformattées en SQLite pour la recherche hors ligne. Aucune
traduction française automatique n’est ajoutée. La colonne `Meaning` de
TBESH n’est pas distribuée dans `strong.db`, car le fichier source demande
une autorisation supplémentaire d’Online Bible avant son utilisation dans
un projet.

Le texte complet des conditions et l’attribution d’origine sont conservés
dans `STEPBible-Data-README.md` et dans les en-têtes des fichiers sources.
